N.B. Please read before starting the Operational Lecture.

  - The index is at the bottom part of the lecture screen.
    Click the index item which corresponds to the part from which you wish to start the lecture.

  - Please check that the font size is set to [Smallest].
    If the text size is not set to [Smallest], the comments in the lecture will not be shown correctly.

To configure the text size : From the toolbar located on the top of the screen, select [View]-[Text Size]-[Smallest].
